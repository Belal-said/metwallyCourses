URL = Uniform Resource Locator
URI = Unified Resource Identifier 

URI = scheme":"hier-part["?"query]["#"fragment]
URL = scheme":"hier-part authority path ["?"query] ["#"fragment]

example = https://cloudnativebasecamp.com:80/courses/nodejs?lesson=01#player

scheme = https
hier-part = //
authority = cloudnativebasecamp.com:80
path = /courses/nodejs
query = ?lesson=01
fragment = #player

Methods = represent the cause of the request. ( Request Verb )
      1- GET => for getting a resource or resources
      2- POST => for creating new resource ( This request method must contain request body )
      3- Put => For editing a resource
      4- DELETE => for deleting a resource


Response status codes:
      1xx informational
      2xx success
      3xx redirect
      4xx client error
      5xx server error
